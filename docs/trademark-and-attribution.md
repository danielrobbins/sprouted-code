# Trademark and Attribution

Sprouted Code is built from Microsoft's MIT-licensed, open-source Visual Studio
Code repository.

Visual Studio Code is a Microsoft product and trademark. Sprouted Code is not affiliated with, endorsed by, or sponsored by Microsoft.

## Naming

Use:

- Sprouted Code
- Sprouted Code Compatibility Build

Avoid using Microsoft product names as the product name for this project.

Descriptive references are acceptable when needed for clarity, for example:

> Microsoft's open-source Visual Studio Code codebase

## Branding Direction

Sprouted Code should avoid broad rebranding in the source tree. The first priority is upstream compatibility and auditability, not a distinct editor identity.

Build identity changes should stay minimal and be documented as build-identity patches.
